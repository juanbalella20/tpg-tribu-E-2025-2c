# tpg-tribu-E-2025-2c
Para correr el frontend con React en debemos estar en la carpeta `frontend/src` y ejecutar:
```
npm install
npm run dev
```

## Módulo carga de horas
Para correr el módulo de carga de horas, debemos estar en la carpeta `backend/horas/` y ejecutar:
```
pip install -r requirements.txt --break-system-packages
```
Luego, para iniciar el servidor, ir a `/api_rest/` y ejecutar:
```
py api.py
```
Esto correra por detrás mientras usamos el frontend.
